Example posts — image-top carousel

Horizontal scroll of example posts with the image on top. Each card uses the linked post's og:image; when a source exposes no usable image (X, Reddit, Instagram, or a placeholder), the thumb falls back to a gradient tile showing the source domain. Handle · platform, caption, then a View post link. The first five cards are real posts covering each image-sourcing pattern (news og:image, YouTube, X, Bluesky, signed/expiring URL); the last shows the domain fallback for a deleted post.
